# Web Portfolio & CV — Kỹ sư Hoàng Đức Thiện

Website Portfolio & CV của **Hoàng Đức Thiện** — Kỹ sư CNTT, ĐH Bách Khoa Hà Nội; phát triển & vận hành hệ thống nghiệp vụ tái bảo hiểm.

* **Live Demo:** [https://quatbathien.github.io/WebCV_Pofolio/](https://quatbathien.github.io/WebCV_Pofolio/)
* **Repository:** [https://github.com/QuatBaThien/WebCV_Pofolio](https://github.com/QuatBaThien/WebCV_Pofolio)

---

## 🌟 Điểm nhấn dự án

1. **Giao diện Obsidian Dark / Cyber Glassmorphism:**
   - Xây dựng theo phong cách hiện đại, chỉn chu (Typography *Space Grotesk* + *Manrope*, hiệu ứng Canvas Particles, Spotlight theo chuột, Smooth Scroll).
   - Thiết kế chuẩn Responsive tối ưu trên Desktop, Tablet và Mobile.

2. **Nội dung hồ sơ:**
   - Hơn 2 năm kinh nghiệm phát triển phần mềm, trực tiếp phát triển & vận hành hệ thống nghiệp vụ tái bảo hiểm tại Trung tâm CNTT PVI từ 08/2024 (.NET, React / React Native, SQL Server).
   - Học vấn: Kỹ sư CNTT, ĐH Bách Khoa Hà Nội (HEDSPI), GPA 3.2/4 — Xếp loại Giỏi. Tiếng Nhật JLPT N3.
   - Bản CV public (`cv.html`, `CV_HoangDucThien.pdf`) đã lược tên hệ thống nội bộ.

3. **Tính năng tương tác:**
   - **Interactive Developer Terminal:** Gõ các lệnh `whoami`, `education`, `experience`, `skills`, `ai-tools`, `projects`, `contact`, `clear`.
   - **AI Chat Drawer Assistant:** Trợ lý ảo giải đáp nhanh thông tin hồ sơ.

---

## 🛠️ Công nghệ phát triển

- **Frontend:** Semantic HTML5, Modern CSS3 (CSS Variables, Backdrop Filters, Keyframe Animations), Vanilla JavaScript (ES6+).
- **CI/CD & Hosting:** GitHub Actions (`.github/workflows/deploy.yml`) tự động build và deploy lên GitHub Pages mỗi khi push code lên nhánh `main`.
